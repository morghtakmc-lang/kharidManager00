# مدیریت خرید و سررسید — نسخه 1.0

اپلیکیشن آفلاین اندروید برای ثبت خرید، مدیریت خریداران/شرکت‌ها/نهاده‌ها، سررسید فرعی و آلارم مستقل هر سفارش، گزارش و خروجی Excel.

## امکانات نسخه اول
- ثبت 14 فیلد خرید
- ذخیره آفلاین روی گوشی
- لیست خریداران، شرکت‌ها و نهاده‌ها با امکان افزودن و حذف
- تاریخ اصلی فقط برای نمایش
- تاریخ فرعی با آلارم مستقل برای هر سفارش
- تعیین تعداد روز قبل و ساعت دقیق هشدار
- آلارم واقعی گوشی + ویبره + اعلان
- لیست خریدها، جستجو و جزئیات
- گزارش فیلترشده و خروجی Excel (.xls قابل باز شدن در Excel)
- پشتیبان‌گیری و بازیابی JSON

## ساخت APK
1. پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle و وابستگی AndroidX دریافت شوند.
3. از Build > Build APK(s) استفاده کنید.
4. روی Android 13+ اجازه اعلان و روی دستگاه‌هایی که لازم است اجازه Exact Alarm را فعال کنید.

## نکته
این نسخه برای استفاده آفلاین طراحی شده و اطلاعات خرید به سرور ارسال نمی‌شود.
